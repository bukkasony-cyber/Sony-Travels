SONY TRAVELS - MULTIPAGE WEBSITE
=================================

Pages:
- index.html   : Home
- about.html   : About
- cars.html    : Our Cars
- booking.html : Booking form
- contact.html : Contact form

Shared files:
- style.css    : White, warm yellow and cream design
- script.js    : Mobile menu, form demo interactions and car preselection

HOW TO RUN:
1. Extract the ZIP folder.
2. Keep all HTML, CSS and JS files together in the same folder.
3. Double-click index.html to open it in Chrome.
4. Use the navigation menu to visit each page.

NOTES:
- Car images and Google Fonts need an internet connection.
- Booking and contact forms are frontend demonstrations only. They do not store data.
- PHP and MySQL backend can be connected in the next development stage.
- Replace sample contact details on contact.html with actual project details if desired.
